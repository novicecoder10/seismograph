`TectonicRegimeTable.dat` is copied unchanged from
`opensha/opensha-oaf/src/main/resources/org/opensha/oaf/rj/TectonicRegimeTable.dat`
(CC0-1.0). It is the Garcia et al. (2012) tectonic regionalisation on a 0.05° grid, the
same table the USGS Operational Aftershock Forecasting system uses to pick generic
parameters. Format and lookup: `lib/oaf/regimes.ts`.
